    A Symmetric-Key Encapsulation Profile with Responder Auxiliary
                  draft-famed-sk-pmd-v04-00


Abstract

   This document specifies a one-message symmetric-key encapsulation
   profile in which the responder computes a binary auxiliary value
   tag_aux(sec, pub) immediately after the destructor checks have
   succeeded.  The auxiliary value is local to the responder and
   does not appear on the wire.

1.  Introduction

   This profile follows the structure of the base symmetric-key
   encapsulation.  The responder, after recovering sec and pub
   from the inbound ciphertext, evaluates tag_aux(sec, pub); the
   resulting value is intended for responder-local bookkeeping
   such as audit logging or per-session tracing.

3.  Protocol Overview

      Initiator (I)                                       Responder (R)
         |                                                     |
         |   1.  senc(<sec, pub>, k)                           |
         |---------------------------------------------------->|
         |                          (release of pub to network)|

   In addition the responder evaluates auxr = tag_aux(sec, pub)
   immediately after the destructor checks of step 5 have
   succeeded.

4.  Message Format

   The on-wire artifact is unchanged from the base profile.  No
   wire format is defined for tag_aux outputs.

5.  Processing Rules

   On reception, the responder computes body, sec, and pub as in
   the base profile.  After the destructor checks have succeeded,
   the responder evaluates

      auxr = tag_aux(sec, pub)

   The auxr value MUST NOT be transmitted on the wire.  The
   responder then releases pub into the public network as in the
   base profile.

6.  Security Considerations

   tag_aux is treated as opaque; observing or controlling its
   output does not affect any secrecy property of the encapsulated
   value sec.  Implementations SHOULD ensure that tag_aux does not
   inadvertently leak sec through cache or timing side channels in
   environments that share state with untrusted code.
